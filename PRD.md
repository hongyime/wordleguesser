# PRD: wordleguesser

## Overview
A Python CLI tool that helps solve Wordle puzzles by filtering a word list based on known constraints (green/yellow/gray letters) and ranking remaining candidates by English word frequency. The user inputs their guesses and the colored feedback; the tool returns a ranked list of best next guesses.

## Goals
- Accept Wordle feedback (green = correct position, yellow = wrong position, gray = not in word)
- Filter a 5-letter word list to candidates that satisfy all constraints
- Rank candidates by real-world English word frequency (from freq_map.json)
- Run as an interactive CLI loop

## Non-Goals
- Automated Wordle bot (no browser automation)
- Web interface
- Hard mode optimization (doesn't minimize expected remaining words)
- Support for word lengths other than 5

## User Stories
- As a Wordle player, I've guessed "crane" and got green C, yellow R — I want the tool to show me best next words.
- As a competitive player, I want frequency-ranked suggestions so I guess common words first.

## Tech Stack
- **Language**: Python 3.x
- **Libraries**: Python standard library (`json`, `pathlib`, `re`, `math`, `sys`)
- **Data files**: `fivewords.txt` (word list), `freq_map.json` (frequency map)

## Architecture
```
wordleguesser/
├── wordleguesser.py   # main script + interactive loop
├── fivewords.txt      # word list (one 5-letter word per line)
└── freq_map.json      # word → frequency weight dictionary
```

**Core function:** `findword(guessed, g=None, y=None, gray='')`
1. Load full word list from `fivewords.txt`
2. Remove all already-guessed words
3. Derive gray letters: characters in guesses that aren't green or yellow
4. Remove words containing any gray letter
5. Remove words not containing all yellow letters
6. Remove words where a yellow letter appears at its wrong position
7. Remove words where a green letter doesn't appear at its correct position
8. Look up each remaining word in `freq_map.json`
9. Return sorted list of `{word, weight}` dicts, highest frequency first

## Features (detailed)

### Constraint Filtering
- **Gray**: letters not in the word at all — removes all words containing these chars
- **Yellow** (format `letter+position`, e.g., `r2`): letter is in word but not at that position
  - Words must contain the letter somewhere
  - Words where the letter is at the specified position are removed
- **Green** (format `letter+position`, e.g., `c1`): letter is confirmed at exact position
  - Words must have this letter at this position

### Frequency Ranking
- `freq_map.json` maps lowercase 5-letter words to a numeric frequency weight
- Words not in the map get weight 0 (still shown, just ranked last)
- Sorted descending by weight — common words appear first

### Interactive Loop
- Runs until user quits (Ctrl+C or EOF); import does not start the loop
- Each iteration: prompt for guessed words, green positions, yellow positions
- Prints ranked results as `rank, word, weight`; malformed clues can be retried
- Resolves bundled data beside the script, independently of the working directory

## Data / Config
| File | Description |
|------|-------------|
| `fivewords.txt` | Complete 5-letter English word list, one per line |
| `freq_map.json` | `{"word": frequency_int}` map for ranking |

## Deployment / Run
```bash
# No pip installs needed — stdlib only
python wordleguesser.py
```

**Input format:**
- Guessed words: `crane,stole` (comma-separated)
- Green: `c1,e5` (letter+1-indexed position)
- Yellow: `r2,a3` (letter+1-indexed position)

## Constraints & Notes
- Word list quality determines solver quality — must be comprehensive 5-letter list
- Frequency map sourced externally (not generated by this script)
- Gray letter derivation: inferred from guessed words minus known green/yellow — may over-eliminate if a letter appears multiple times
- No duplicate handling for repeated letters in a guess (known Wordle edge case)
